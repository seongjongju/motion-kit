MotionKit

GSAP와 mo.js를 클래스 하나로 쉽게 쓰게 해주는 클래스 기반 모션 번들입니다. HTML 요소에 ani-* 클래스를 붙이면 스크롤 진입, 호버, 클릭 모션이 기본값으로 재생됩니다. 별도 빌드나 초기화 스크립트 없이 파일만 연결하면 바로 사용할 수 있습니다.

사용 전에 꼭 확인하세요
  1. 정밀한 작업은 별도 조작이 필요합니다. 페이지 구조에 맞춘 타임라인 진행바 같은 스크롤 연동은 이 번들 범위에 없습니다.
  2. 새로운 라이브러리가 아닙니다. 이미 존재하는 GSAP·mo.js를 편하게 사용하기 위해 만든 모음입니다.
  3. gsap, mo.js, ScrollTrigger 등 번들에 연결된 파일(CDN 포함)을 모두 연결해야 합니다.
  4. 스크립트는 마크업 최하단에 연결하므로, 공통 inc footer 파일에 넣어 관리하세요.

사용 가이드

1. 파일 연결

CSS는 <head>에, 스크립트는 공통 footer의 </body> 직전에 연결합니다.
스크립트는 내 경로 또는 CDN으로 연결하세요.

2. 기본 사용법

클래스 한 줄이면 기본 동작이 시작됩니다. 아래 결과는 문서용으로 data-ani-trigger="load"를 넣어 페이지 로드 직후 재생합니다.

4. 반응형 설정

구간은 ≤767px / 768~1023px / ≥1024px입니다. 기본값은 MotionKit.config.breakpoints = { mobile: 767, tablet: 1023 }이고, 값을 바꾸려면 DOMContentLoaded 전에 설정하세요. mobileScale(기본 0.6)은 모바일 구간의 이동 거리와 ani-burst의 반경·개수에 곱해집니다.

호버 모션은 (hover: hover) and (pointer: fine)에서만 바인딩됩니다. ani-burst 버튼에는 touch-action: manipulation을 권장합니다.

5. 스크롤 복원 (data-ani-repeat)

기본값은 once입니다. reverse는 아래로 스크롤해 화면을 벗어나면 되감고, replay는 진입할 때마다 처음부터 다시 재생합니다. 두 모드는 ScrollTrigger가 필요하며, 없으면 once로 동작하고 콘솔 경고가 한 번 출력됩니다. ani-count는 repeat 대상이 아닙니다.

6. JS API

동적으로 추가한 DOM은 컨테이너를 넘겨 MotionKit.init(container)를 호출하면 됩니다. refresh는 init과 같은 함수입니다.

7. 연결이 안 될 때 확인할 것

증상 / 콘솔 메시지확인할 것
[MotionKit] gsap를 motion-kit.js보다 먼저 불러와 주세요.vendor/gsap.min.js가 motion-kit.js 앞에 있는지 확인합니다. 이 경우 ani-fail이 붙어 요소가 모두 표시됩니다.
[MotionKit] ScrollTrigger가 없어 ...vendor/ScrollTrigger.min.js 경로를 확인합니다. 없으면 반복 옵션만 once로 동작합니다.
[MotionKit] mo.js가 로드되지 않아 ani-burst를 건너뜁니다.mo.js CDN 주소와 네트워크를 확인합니다. 버스트만 건너뛰고 다른 모션은 계속 동작합니다.
요소가 처음부터 보이거나 반대로 계속 숨겨집니다CSS가 <head>에 있는지, JS가 </body> 직전에 있는지, 스크립트 순서가 gsap → ScrollTrigger → mo.js → motion-kit인지 확인합니다.
추가한 DOM이 움직이지 않습니다삽입 후 MotionKit.init(컨테이너)를 호출했는지 확인합니다.
